Teaching Assistant

Course Overview

This course is an introduction to Data Mining, also referred to as Machine Learning or Statistical Learning, a foundational area of Artificial Intelligence concerned with how algorithms can learn from data and experience. At its core, data mining enables machines to discover patterns, build knowledge, make predictions, and support decisions, providing fundamental building blocks for human-like intelligence and, ultimately, the possibility of general and superintelligent AI. The course introduces a range of foundational methods, providing both a theoretical understanding of how and why they work and practical experience in implementing, evaluating, and applying them to real-world problems.

Course Objectives and Learning Outcomes

The objective of this course is to give students a foundation in machine learning, including important problems like classification, regression, clustering, and dimensionality reduction. The emphasis will be on understanding the design of various machine learning methods, learning how to use them in practice, and learning principled ways to evaluate their performance. The labs will complement the lecture topics by offering practical experience in experimenting with machine learning methods. To succeed in this course, knowing the following areas is vital:

  • Programming with Python (Intermediate to Advanced)
  • Probability and Statistics (Introductory to Intermediate)
  • Linear Algebra (Introductory to Intermediate)

Topics

The topics include the interplay between data mining (1) tasks, (2) machine learning approaches, and (3) the techniques used to address the tasks via an approach:

  • Tasks
    • Classification
    • Regression
    • Clustering
    • Ranking (Recommendation)
    • Vector Representation and Dimensionality Reduction
    • Language Modeling
  • Approaches 
    • Supervised Learning 
    • Unsupervised Learning
    • Reinforcement Learning
  • Techniques
    • Naive Bayes
    • Logistic Regression
    • Artificial Neural Networks
    • Graph Neural Network
    • K-Means
    • Support Vector Machines
    • Principal Component Analysis
    • K-Nearest Neighbor
  • Evaluation Strategies
    • Model Tuning and Selection
    • Cross Validation

Assessment

A semester-long group project, a midterm exam, and a final exam are the main components of the assessment, as well as additional bonus points. The details are:

  • This course is project-driven. Students work in groups to complete a data mining project over one semester spearheaded by a graduate student, following five project milestones. The project focuses on applying the theories and technologies introduced in the course to address a real-world problem. Each group defines a clear problem statement, identifies and prepares training datasets, selects suitable machine learning approaches and benchmarks machine learning methods, and evaluates and interprets the results. At each milestone, students submit a project deliverable, including a report prepared according to the guidelines provided in the project manual. Graduate students also gain practical project management and collaboration skills that can support their future research and work within research groups. Marks might not be the same for all students in a project group.
  • Unless an alternative consideration is approved in accordance with the Academic Concessions Regulation, a mark of zero will be assigned for a missed assessment item or late submission. There are no make-up examinations. If a midterm examination is missed, its weight will be transferred to the next examination. If the final examination is missed, the student’s overall collected mark will be assigned as the final course grade.

Participation

In-person class attendance is not mandatory but strongly recommended. However, there are two presentations on the course group project that must be delivered in person by the members of the presenting group.
